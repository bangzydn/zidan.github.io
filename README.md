# Website Perusahaan Pelayaran - PT. Maritim Sejahtera

Website perusahaan pelayaran modern dan profesional yang dirancang untuk PT. Maritim Sejahtera, sebuah perusahaan pelayaran yang bergerak di bidang jasa tug & barge dan penyewaan kapal.

## 🚢 Fitur Utama

### Halaman Utama (`shipping-company.html`)
- **Hero Section** dengan animasi dan gradient maritim
- **Tentang Kami** - Profil perusahaan, visi, misi, dan sejarah
- **Layanan** - Jasa tug & barge dan penyewaan kapal
- **Armada Kapal** - Galeri dan spesifikasi kapal
- **Proyek & Galeri** - Dokumentasi proyek-proyek sukses
- **Berita & Artikel** - Update perusahaan dan industri
- **Investor** - Informasi keuangan dan laporan
- **Karier** - Lowongan kerja dan keuntungan bergabung
- **Hubungi Kami** - Formulir kontak dan informasi

### Halaman Detail Layanan (`layanan-detail.html`)
- **Jasa Tug & Barge** - Spesifikasi lengkap layanan
- **Penyewaan Kapal** - Paket dan harga sewa
- **Proses Kerja** - Langkah-langkah mendapatkan layanan
- **Call-to-Action** - Tombol kontak dan penawaran

### Halaman Investor (`investor.html`)
- **Ikhtisar Data Keuangan** - Performa keuangan perusahaan
- **Laporan Keuangan** - Download laporan tahunan dan triwulan
- **Struktur Pemegang Saham** - Komposisi kepemilikan
- **Kebijakan Dividen** - Riwayat dan target dividen
- **RUPS** - Informasi rapat pemegang saham
- **Investor Relations** - Kontak tim investor

## 🔧 Cara Menjalankan

1. **Clone Repository**
   ```bash
   git clone [repository-url]
   cd shipping-company-website
   ```

2. **Install Dependencies** (jika menggunakan npm)
   ```bash
   npm install
   ```

3. **Build CSS** (jika menggunakan Tailwind CLI)
   ```bash
   npx tailwindcss -i ./input.css -o ./output.css --watch
   ```

4. **Buka di Browser**
   - Buka `shipping-company.html` di browser
   - Atau gunakan live server untuk development
