# ClipAI Advisor - AI Assistant untuk Agensi Kliping

## 🎯 Deskripsi
ClipAI Advisor adalah aplikasi full-stack RAG (Retrieval-Augmented Generation) chatbot yang membantu creator dan agensi kliping dengan pengetahuan dari kvmedia. Aplikasi ini mengubah konten video panjang menjadi klip pendek untuk platform seperti TikTok, Instagram Reels, dan YouTube Shorts.

## 🏗️ Arsitektur
- **Frontend**: Next.js 15 + TypeScript + Tailwind CSS
- **Backend**: FastAPI + Python
- **Database**: PostgreSQL (Supabase) + Pinecone Vector DB
- **AI/LLM**: Grok API (xAI) / OpenAI GPT-4o
- **RAG Framework**: LangChain / LlamaIndex
- **Deployment**: Vercel (Frontend) + Heroku/AWS (Backend)

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- Python 3.9+
- Docker (optional)

### Development Setup
1. Clone repository
2. Setup backend: `cd backend && pip install -r requirements.txt`
3. Setup frontend: `cd frontend && npm install`
4. Configure environment variables
5. Run development servers
